# Task 2: Number Guessing Game 🎮

## 📌 Project Overview
This project is part of my **Oasis Infobyte Internship (Python Programming)**.  
It is a simple interactive game where the computer generates a random number between 1 and 100, and the user tries to guess it.  
The program provides hints ("Too high" / "Too low") and counts the number of attempts until the correct guess is made.

---

## ⚙️ Features
- Random number generation between 1–100.
- Input validation (handles non‑numeric values and out‑of‑range guesses).
- Tracks number of attempts.
- Friendly messages for user guidance.

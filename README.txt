# BMI Calculator (Python)

This project calculates Body Mass Index (BMI) based on user input of weight (kg) and height (m).  
It outputs the BMI value and category (Underweight, Normal, Overweight, Obese).

## Features
- Input validation (no negative or zero values)
- BMI formula: weight / (height^2)
- Categorization based on standard BMI ranges

## Demo
Example:  
Weight = 60 kg, Height = 1.65 m → BMI: 22.04 (Normal weight)
